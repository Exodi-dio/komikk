# komikk

A next-generation comic/manga reader for Android. The better version of every
Tachiyomi fork.

Android-native (Kotlin Multiplatform, Android-first), built around a clean,
testable source/extension architecture instead of the separate-APK extension
model Tachiyomi and its forks rely on.

- `plans/komikk-source-system.md` — the construction plan for the first
  milestone (source/extension core).
- `catalog/README.md` — living architecture docs (landed when Step 6 does).
- `AGENTS.md` — operating rules for agents working in this repo.
